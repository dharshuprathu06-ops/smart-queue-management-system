 Smart Queue Management & Waiting-Time Prediction System

A web-based queue management system that provides digital token generation, queue tracking, and estimated waiting-time information.

 Features

- Digital token generation
- Service-wise queue management
- Real-time queue status tracking
- People-before-you count
- Estimated waiting time
- Token tracking using token number
- Admin dashboard for queue management
- Call-next token functionality
- MySQL database integration
- Secure database password handling using environment variables

 Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Jinja2
- mysql-connector-python
- python-dotenv

Services

The system supports multiple services:

- General Consultation
- Registration
- Billing
- Enquiry

 How It Works

1. User selects a service.
2. The system generates a digital token.
3. The user can view their queue position.
4. The system calculates the estimated waiting time.
5. Users can track their token using the token number.
6. Admin can monitor the queue and call the next token.
